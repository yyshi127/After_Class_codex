# 家长端使用说明

## 1. 首页

家长登录后可以查看孩子今日状态，包括到校、离校、请假、缺勤等信息。老师完成拍照签到后，家长会收到孩子已到校通知。

## 2. 作业反馈

家长可以查看：

- 作业原图。
- AI 圈错建议图。
- 老师批改图。
- 老师文字点评。

这些内容用于真实反映孩子当天作业状况。

## 3. 今日点评

老师发布后，家长可以查看三类总结：

- 行为表现。
- 作业完成。
- 知识掌握。

## 4. AI 助手和请假

家长可以通过 AI 助手查询今日状态、作业情况、服务有效期，也可以生成请假确认卡片。请假提交后由老师或机构确认。

## 5. 服务信息

家长端只展示服务有效期和续费提示，不展示余额、欠费金额、班级核算、机构收入、老师课费和班级毛利。

## 6. 隐私说明

身份证号、作业图片、签到照片只用于托管、研学、保险、出行实名和家校沟通等必要业务场景。
