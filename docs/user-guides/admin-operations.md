# 晚辅托管系统管理员操作手册

## 1. 上线前准备

1. 确认校区、班级、老师、学生、家长资料已按导入模板整理。
2. 确认 4 种托管类型已存在：中午托、下午托、晚辅导、晚全托。
3. 确认默认管理员账号已修改密码，生产环境已配置 `JWT_SECRET` 和 `ENCRYPTION_KEY`。

## 2. 日常工作

1. 首页看板查看今日托管人数、出勤率、待处理请假、作业完成率和风险提醒。
2. 学生档案维护学生基础资料、身份证号、家长绑定、班级和托管类型。
3. 考勤页面查看学生签到、请假、缺勤和老师考勤。
4. 作业页面查看老师发布的作业原图、AI 圈错建议、批改图和错题记录。
5. 财务页面查看月缴/学期缴记录、服务有效期、余额/欠费和班级核算。
6. AI 日志页面查看 AI 识别、确认、拒绝和失败原因。

## 3. 权限注意事项

- 家长端不展示余额、欠费金额、班级核算、机构收入、老师课费和班级毛利。
- 身份证号完整查看必须有管理员权限，并会写入审计日志。
- 跨校区访问、图片访问、费用查看都会写入审计日志。
- AI 写入类动作必须经过老师或管理员确认。
