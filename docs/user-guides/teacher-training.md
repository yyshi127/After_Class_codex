# 老师端培训材料

## 1. 今日工作台

1. 登录后进入老师工作台，先选择负责班级。
2. 放学到托后为学生拍照签到，系统会通知绑定家长。
3. 对请假、缺勤、已到校状态进行核对。
4. 查看服务到期提醒，但不查看班级毛利等经营数据。

## 2. 作业批改

1. 进入班级和学生，上传作业原图。
2. 系统生成 AI 圈错建议和批改草稿。
3. 老师确认或修改后发布批改图。
4. 发布后家长可查看作业原图、AI 圈错图、老师批改图。
5. 错题会先进入候选状态，老师确认后进入错题本。

## 3. 错题和练习单

1. 老师确认错题知识点。
2. 生成同类题，选择适合学生的题目。
3. 生成 Word 练习单后打印给学生练习。

## 4. 今日点评

点评分为三类：

- 行为表现：课堂纪律、状态、配合度。
- 作业完成：完成度、订正情况、书写情况。
- 知识掌握：知识点掌握、薄弱点和复习建议。

AI 可以生成草稿，但最终发布必须由老师确认。
